# Lean Her Way social hub

This repository contains the mobile-friendly landing page used by the QR code on
Lean Her Way business cards. Its URL is <https://www.leanherway.com/connect/>.

The print-ready QR artwork is `business-card-qr.svg`. The landing page is served
from the existing Lean Her Way website.

## Publish with GitHub Pages

The landing page itself is maintained in the `leanherway` website repository at
`connect/index.html`; that repository publishes it under `www.leanherway.com`.
