# Lean Her Way social hub

This repository contains the mobile-friendly landing page used by the QR code on
Lean Her Way business cards.

The print-ready QR artwork is `business-card-qr.svg`. It points to the GitHub
Pages URL below; do not print it until the page is deployed and the URL opens
successfully.

## Publish with GitHub Pages

The site is configured to deploy from the `main` branch with GitHub Actions.
In the repository settings, set **Pages → Build and deployment → Source** to
**GitHub Actions**. Push changes to `main` (or run the “Deploy to GitHub Pages”
workflow manually) to publish the site at:

<https://mahrukhraza05.github.io/lhw-qr/>

GitHub Pages must be available for this private repository's plan. If Pages
cannot be enabled, transfer the site to a public repository or another static
host before printing the QR code.
